# Microsoft Azure Administrator (AZ‑104) – Hands‑On Labs Showcase

This repository contains Azure resources and notes recreated from the official Microsoft AZ‑104T00‑A: Azure Administrator course, using my own Azure subscription. The goal is to demonstrate practical skills in identity, governance, networking, connectivity, and resource management.

## Labs Recreated

1. Manage Microsoft Entra ID Identities  
2. Manage Subscriptions and RBAC  
3. Manage Governance via Azure Policy  
4. Manage Azure Resources using ARM Templates  
5. Implement Virtual Networking  
6. Implement Intersite Connectivity  
7. Implement Network Traffic Management  

## Repository Structure

- `notes/` – Lab-by-lab explanations of what was built and why  
- `screenshots/` – Azure Portal screenshots  
- `templates/` – Exported ARM templates from my own Azure environment
